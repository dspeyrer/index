# Index

This is a YouTube video tracker with two primary motivations:

- YouTube's tracking of the last watch time on a video is lacklustre
- After [discontinuing notification emails](https://support.google.com/youtube/thread/63269933), there is no longer any reliable way of ensuring you don't miss an upload

This web app aims to address these and provide a lot of nice other features along the way.

## Feature tracker
- [x] Basic video list
- [x] Video playback time tracking
- [x] Client-side storage backend
- [ ] Server-side storage backend
- [ ] Integrated SponsorBlock
- [ ] Channel subscriptions
- [ ] Detailed watchtime data
- [ ] Undoable seeking
- [ ] Tagging, categorization, and sorting of lists

- [ ] Integrated channel page
